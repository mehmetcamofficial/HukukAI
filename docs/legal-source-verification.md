# Legal Source Verification

Every important legal statement needs a traceable source. A source card should contain provider name, title, date, URL/reference, retrieval date, excerpt, and verification status.

Supported statuses:

- `DOĞRULANDI`
- `KISMEN DOĞRULANDI`
- `DOĞRULANAMADI`
- `DEMO VERİ`

The current demo provider deliberately uses `DEMO VERİ` and `DOĞRULANAMADI`. When a source cannot be verified, the interface must display `Kaynak doğrulanamadı.` and must not style the result as confirmed law. Semantic similarity is an information-retrieval signal, not legal authority.
